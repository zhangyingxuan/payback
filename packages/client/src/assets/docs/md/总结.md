# 问题：
1. 如何判断强市 弱市？
   价格：强势：涨大于跌，指数上涨，
   成交量变化：强市：成交量持续放大，弱市：持续萎靡
   板块轮动：强市：板块轮动上涨，有序，弱市：板块轮动不明显，且混乱
   投资者情绪：强市：对市场充满信心，乐观；弱市：对市场谨慎，悲观
   技术指标分析：均线/趋势线/技术图形；强市：多头，弱市：空头

2. 变盘怎么判断，情绪标的
   技术指标分析：macd/kdj 金叉/死叉；见顶/见底反转
   成交量变化：趋势变化，反转
   政策面变化：利好：降息/降准；利空：下调准备金
   行业板块走势：不同板块走势不同步。（统计76行业板块，涨跌数）
   市场情绪变化：态度转变

3. 半路低吸准确含义？
   半路是指上涨到一定程度买入；低吸是指下跌时较地位买入，上涨后卖出。

4. 止跌怎么判断？
   股价：下跌过程中出现反弹，且反弹力度逐渐增强，成交量放大，则初步止跌。价格稳定在某个区间，且不创新低，停止下跌，处于横盘整理。
   成交量：成交量逐渐放大，可能止跌。成交量逐渐萎靡，没有止跌。
   技术指标：金叉
   公司基本面变化：利好消息：盈利增长/分红转送；利空消息：亏损加大，股价持续低于净资产。
   市场情绪变化：转换

5. 涨停强势股的筛选标准？
   涨停板未被打开过，即股票走势强劲。
   早市跳空开盘，小幅回档后直接快速封停，表明主力积极上攻。
   涨停后未出现过四位数的抛盘，涨停后量极度缩小，表明主力控盘良好。
   封单为五位数，表明市场交易活跃。
   日K线在季托之上，股价正处于主力拉升初期或中期。
   刚创新高，且未远离底位成交密集区。
   属于资金流向中的主流板块品种。

6. 回封强势板。
   好处：能够让前期获利筹码继续锁定，减轻后续股价上升的压力，同时抬高市场成本，对后续股价回调会有强劲的支撑。
   在打回封强势板时，需要注意以下几点：
   注意观察分时线的形态，如果分时线纠缠紧密，大概率是分不出胜负的，最好的图形是回封的时候，强势个股能和其他两个大幅拉开距离，上板的一瞬间有直线拉升的冲击波，这就说明它的强度比其他的大很多。
   设置涨幅大于9%的预警，这样能够及时捕捉到回封强势板的机会。
   打回封板要跟随多头分歧转一致之后的资金，谁先封住就证明谁最强大，最有可能成为龙头。

7. 股性怎么判断？
   换手率：换手率越高，股票的活跃度越高，股性越好。>5%
   成交量：成交量越大，股票的活跃度越高，股性越好。(首板倍量最佳)
   价格波动范围：价格波动范围越大，股性越强。
   消息面情况：有利的消息面能够提升投资者的信心，从而提升股票的活跃度和股性。

8. 辨识度？
   特殊性质可能包括股票的价格、成交量、波动性、行业、题材、公司背景等方面的特征。
   辨识度通常是通过股票的技术分析、基本面分析、市场情绪分析等方式来获得的

9. 反抽反弹怎么定义？
   “反抽”经历了一波下跌后，出现短暂的回升走势，但回升力度较弱，持续时间较短，一般持续几个交易日就会再次下跌。反抽通常被视为短期内的技术调整，是短线交易的机会，但并不代表趋势已经反转。
   “反弹”经历了一波下跌后，出现较为强劲的回升走势，持续时间相对较长，通常会持续数个交易周或数个月。反弹通常被视为市场的一种超跌修复，也是投资者进行波段操作的机会。

10. 超跌
   “超跌”指的是股票价格跌到远低于正常价值的位置，通常指的是短期内的过度下跌。超跌通常是由于市场恐慌、股票抛售等短期因素导致的，而这些因素可能并不代表股票的基本面发生了变化。
   重点关注基本面（业绩下滑、债务违约—）是否变化？

11. 基本面
   公司的财务状况：包括公司的资产、负债、利润、现金流等财务数据，这些数据反映了公司的实际经济实力和经营状况。
   公司业绩：包括公司的销售额、市场份额、利润率、增长率等业绩数据，这些数据反映了公司的经营表现和竞争优势。
   公司战略：包括公司的市场定位、产品线、竞争策略、发展方向等战略规划，这些数据反映了公司的未来发展潜力和投资价值。
   行业情况：包括行业的市场规模、增长率、竞争格局、发展趋势等行业数据，这些数据反映了公司所处行业的发展环境和前景。
   市场情绪：包括市场供求关系、投资者情绪、行业热点等市场数据，这些数据反映了市场的风险和机会，也会对股票价格产生影响。

12. 破位（打破关键位置）
    穿破了关键支撑位或阻力位，打破了原有的平衡状态，进入了新的价格区间，新的趋势或趋势延续

14. 盘感
    盘感是指一种通过经验的积累和对市场走势的观察，能够敏锐地感知市场趋势、价格波动等，并做出相应的投资决策的能力。盘感通常是通过长期的观察、实践和经验积累而形成的，对于金融投资领域的人来说，拥有良好的盘感可以帮助他们更好地把握市场动态，做出更为准确的决策，从而实现投资收益的最大化。

   盘感的具体表现形式可以是对于市场趋势的准确判断、对于价格波动时点的精准把握、对于市场情绪的敏锐感知等。拥有良好盘感的人，通常可以快速地做出决策，并且能够根据市场变化及时进行调整，以适应市场的需求和变化。

   需要注意的是，盘感虽然是一种非常重要的投资能力，但并不能保证每一次的投资决策都是正确的。在投资决策时，还需要结合其他因素，如基本面分析、技术面分析等，进行综合评估，以降低风险，提高投资收益。

15. 补涨与跟风
   补涨(注重基本面、成长性)是指股票在相关板块或指数上涨时，由于其价格被低估或基本面得到改善，从而出现上涨的情况。补涨股往往是在市场趋势明确后才开始上涨，它的涨幅通常会受到基本面的支撑，具有持续性和稳健性。补涨股的上涨动力主要来自于其自身的成长性和估值修复，与市场情绪和投资者情绪的影响相对较小。

   而跟风（注重市场情绪、投资者情绪）个股则是指跟随市场热点或强势股上涨的股票。跟风股的主要上涨动力来自于市场情绪和投资者情绪的影响，其涨幅往往与市场趋势无关，而是取决于投资者的追涨杀跌情绪。跟风股的走势较为波动，涨跌幅度较大，具有一定的投机性。
