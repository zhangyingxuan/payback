# 数据库设计

> 最后验证：2026-10-13

MySQL 5.7，TypeORM `synchronize: true`（entity 即表结构，无迁移脚本）。表名=类名（默认策略）。entity 位置：`packages/server/src/{pay-back,users,article}/entities/*.entity.ts`。

## 核心数据表（按交易日一条记录为主）

### fundsData — 资金数据（11:41/15:45 采集）
| 字段 | 类型 | 说明 |
|------|------|------|
| tradeDate | date | 交易日期 |
| northFundsAmtIn / northFundsBuyAmt | float | 北向资金净流入/净买入 |
| southFundsAmtIn / southFundsBuyAmt | float | 南向资金净流入/净买入 |
| hangyeFundsTop / gainianFundsTop | varchar(1024) | 行业/概念板块主力资金 Top |
| marketTurnover | float | 市场成交总额 |
| createTime | timestamp | 默认 current_timestamp |

### marketData — 大盘市场（11:31/15:10）
tradeDate、marketScore(大盘评级 float)、riseAmount/fallAmount(smallint 涨跌家数)、riseMore5/fallMore5(±5% 家数)、dailyLimitIncome(昨日涨停今日收益)、marketTurnover、shangzhengRiseAndFall/shangzhengPoint/shenzhengPoint/chuangyePoint/beizheng50Point(decimal(8,2))、gainianRiseFloat/gainianFallFloat/hangyeRiseFloat/hangyeFallFloat(varchar512 板块 TOP5)、createTime。

### shortTermData — 短线情绪（11:36/15:35）
tradeDate、dailyLimitQuantity(涨停数)、dailyLimitOpenQuantity(涨停打开)、dailyLimitReturnSealQuantity(回封)、downLimitQuantity(跌停数)、hugeFallQuantity(跌≥15% 数)、sealingRate(tinyint 封板率)、marketHeight(tinyint 最高连板)、evenBoardAmount(连板数)、**evenBoardData(mediumtext 连板原始数据)**、downLimitData(varchar8192)、hugeFallData(varchar4096)、cycle(短线周期)、createTime。

### plateData — 板块涨停（11:33/15:40）
tradeDate、gainianDailyLimitNum/gainianDailyLimitData、hangyeDailyLimitNum/hangyeDailyLimitData（涨停最多的概念/行业板块，float+varchar512）、createTime。

### hotList — 热榜（7-23 点每 30 分，滚动更新）
stockNormal(热门个股大家都在看 Top10 varchar2048)、stockValue(价值投资 Top10)、plateConcept/plateIndustry(板块 Top5)、hotEtfs(ETF Top5)、createTime、updatedTime。**无 tradeDate，按时间戳判断新鲜度。**

### latestConceptPlate — 最新概念板块（9:05/16:00/23:00）
name(varchar30)、code(varchar10)、createTime。滚动新增，用于发现新题材。

### specialStock — 新股与策略标的（9:25/11:40/15:37，竞价 11:38/15:33）
tradeDate、昨日涨停今日集合竞价情况（**mediumtext**）等字段；驱动早盘飞书卡片与自选同步。

### reviewData（类 review）— 复盘（review service 生成）
cycle/dateCycle(短线/时间周期)、marketScore(float)、marketMood/toujiMood/plateMood(当日市场/投机/板块情绪 varchar30)、overallMarketMood/overallToujiMood/overallPlateMood(近期)、moneyMakingEffect/moneyLossEffect(赚钱/亏钱效应)、totalLeader/plateLeader(总/板块龙头)、strongestPlate/strongestTopic(最强板块/题材)、hotStocks(人气股 varchar512)、fundsLikeStocks(资金青睐个股)、createTime。

## 配置与账号表

### systemConfig — 系统配置（单行使用）
isAutoAddSelf(收盘自动加自选 0/1)、isAutoAddSelfEvenBoard(连板)、isAutoAddSelfFirstBoard(首板)、baseConfig(varchar512 JSON 串)、biddingConfig(竞价配置 JSON 串)、isBinddingDelEventBoard/isBinddingDelFirstBoard(竞价删除开关)、isAutoPushNews(自动推新闻)、createTime/updatedTime。tinyint(1) 映射 boolean。

### user — 用户
name、account(varchar20)、password(varchar100)、user/ticket/userid(varchar256/520，存同花顺登录票据——敏感，勿日志输出)、isAdmin、isDelete(软删)、createTime。

### article — 文章
title(varchar200)、content(text)、createTime、updatedTime(@UpdateDateColumn)。

## 通用注意

- 所有业务时间字段用 `@Column default current_timestamp`，非 @CreateDateColumn（历史遗留，保持一致）。
- 集合类字段是**序列化字符串**（varchar/mediumtext），非 JSON 列——MySQL 5.7 有 JSON 类型但项目未用，查询解析全在应用层。
- tradeDate 为 `date` 且 nullable：存在同日期多条记录的可能，去重逻辑在 service 层。
- **无唯一索引声明**：按日期取最新一条靠 ORDER 逻辑，加数据时注意重复。
- synchronize: true 意味着改 entity 即改表：删字段=删列，改类型=隐式 ALTER，务必先在 dev 库验证。
