# 接口文档

> 最后验证：2026-10-13

全部 REST 端点清单。**全局前缀 `/blowsysun`**；除 `@Public()` 外均需 JWT（登录后 Bearer token）。参数与响应细节以对应 controller 源码为准（本表按代码实测生成）。

## auth — src/auth/auth.controller.ts

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| POST | /auth/login | 账密 + svg-captcha 登录，返回 JWT | Public |
| GET | /auth/profile | 当前用户信息 | 需要 |
| GET | /auth/getCode | 生成图形验证码 | Public |

## pay-back（核心） — src/pay-back/pay-back.controller.ts

采集触发（POST）：`/pay-back/crawlTodayData`、`/crawlBinddingData`（竞价）、`/crawlSpecialStockData`（新股/强势股）、`/deleteData`。
采集触发（GET）：`/crawlHotListData`、`/crawlShortTermByDate`、`/crawlPlateData`。
查询：`/list`、`/fetchEvenBoardData`（Evenly 板）、`/fetchDataHealth`（数据完备性）、`/fetchHostListData`（热榜）、`/fetchReveiwDataByDate?date=`（复盘）、`/findConceptPlateWithinNDays`、`/findConceptPlateByLimit`、`/findPlateByLimit`、`/fetchPlateOrderByDailyLimit`、`/fetchLatestNews`。
其他：`GET /testApi`、`POST /saveUserInfo`、`GET /initSchedulerTask`（重载任务表）。

## ths-trade — src/pay-back/ths-trade.controller.ts

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /ths-trade/modifyThsSelfStocks | 批量同步自选（尾盘自动任务同款逻辑） |
| POST | /ths-trade/addThsSelfStock / delThsSelfStock | 按代码增/删自选股 |
| POST | /ths-trade/addThsSelfPlate / delThsSelfPlate | 按代码增/删自选板块 |
| POST | /ths-trade/addThsSelfPlateByNameCn / delThsSelfPlateByNameCn | 按中文名增/删自选板块 |

## system-config — src/pay-back/systemConfig.controller.ts

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /system-config/fetchSystemConfig | 读全部配置（自选开关、竞价配置等） |
| POST | /system-config/updateSystemConfig | 更新配置 |
| POST | /system-config/toggleNewsPushEnable | 新闻推送开关 |

## article — src/article/article.controller.ts

`POST /article/create|remove|update`；`GET /article/findAll|findOne|findByTitle`。

## app（健康检查） — src/app.controller.ts

`GET /blowsysun/`、`GET /blowsysun/test`。

## webhook-server（独立服务 :3002）

`POST /webhook`（Gitee push 事件，验签见推送与部署方案）；`GET /webhook/generateSignature`。

## 约定与坑

- 命名大小写混用（fetchReveiwDataByDate 拼写如此、含历史 typo），前端 `api/payBack.ts` 与之一一对应，改路径要双端同步。
- push-server 无 HTTP 接口，只接受 TCP 事件。
- Swagger 依赖已装（DTO 有 ApiProperty），但 main.ts 未挂载文档端点。
