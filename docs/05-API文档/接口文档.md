## pay-back（核心） — src/pay-back/pay-back.controller.ts

调度行为更新（2026-11-12）：初始化任务及新闻开关所注册的 Cron 均受 core 交易日历过滤，只有热榜豁免；缺失年度日历时跳过受限任务并记录警告。接口路径、请求和响应不变，手动采集不受此门禁影响。

采集触发（POST）：`/pay-back/crawlTodayData`、`/crawlBinddingData`（竞价）、`/crawlSpecialStockData`（新股/强势股）、`/deleteData`。
采集触发（GET）：`/crawlHotListData`、`/crawlShortTermByDate`、`/crawlPlateData`。
查询：`/list`、`/fetchEvenBoardData`（Evenly 板）、`/fetchDataHealth`（数据完备性）、`/fetchHostListData`（热榜）、`/fetchReveiwDataByDate?date=`（复盘）、`/findConceptPlateWithinNDays`、`/findConceptPlateByLimit`、`/findPlateByLimit`、`/fetchPlateOrderByDailyLimit`、`/fetchLatestNews`。
实时行情：`GET /pay-back/live-market/:section`，`section` 为 `market`、`funds`、`shortTerm`、`global`、`turnover`、`stocks` 或 `commodities`；直连上游、不写数据库，同模块并发请求合并。市场指数取自腾讯，题材取同花顺涨停题材样本，题材请求失败时 `sectorUnavailable` 为 true；短线取同花顺涨停池和连板梯队（沪深、创业板、科创板），资金取东方财富行业板块；行情可能延迟，未提供的字段为空。外围市场新增东方财富韩国 KOSPI（KS11）和日经 225（N225）；日韩报价时间为交易所当地时间 UTC+9，腾讯与东方财富独立失败降级，缺失报价保留空值席位。涨停题材 `gainianRiseFloat` 中的 `limitUpCount` 为同花顺 `limit_up_num` 统计家数，缺失返回 null；前端按涨幅降序展示前 20 名，左右分别为 1–10、11–20 名。深证成指、创业板指涨跌幅分别通过 `shenzhengRiseAndFall`、`chuangyeRiseAndFall` 返回（百分数，缺失为 null）。市场宽度 `riseAmount`、`fallAmount` 为东方财富沪深市场上涨、下跌家数之和，不含北交所；任一市场缺失时两项均返回 null，不影响指数返回。短线梯队个股的 `turnoverRate` 为换手率百分数，`closingFunds` 为封单金额（亿元）；来自涨停池的 `turnover_rate`、`order_amount`（元），缺失或异常值为 null，零值保留。

新增行情（2026-11-17）：`turnover` 取同花顺 fuyao 分时最后一个有效配对点，返回 `current`、`previous`、`change`（亿元）、`changePercent`（百分比）、`createTime`；分时缺失时通过当前额与同期差额回退，禁止使用昨日全天表头替代同期额。`stocks` 返回沪深 A 股成交额前十数组：`code`、`name`、`change`（百分比）、`turnover`（亿元）、`industry`。`commodities` 返回固定黄金（贵金属 BK0732）和原油（石油石化 BK0464）板块数组：`code`、`name`、`change`（百分比），不是商品期货报价。
其他：`GET /testApi`、`POST /saveUserInfo`、`GET /initSchedulerTask`（重载任务表）。

## 约定与坑

- 命名大小写混用（fetchReveiwDataByDate 拼写如此、含历史 typo），前端 `api/payBack.ts` 与之一一对应，改路径要双端同步。
- push-server 无 HTTP 接口，接受 TCP 事件与请求；`pushReviewCharts` 使用请求响应，返回 `{ok, failures}`，失败通道以 `wecom:索引` / `feishu:索引` 标识。
- Agent 内网 `POST /review-charts/YYYY-MM-DD` 返回 `{data_as_of, charts: [{name, svg_base64}]}`（`panorama`、`ladder` 各一张）；日期无效返回 400，同日收盘数据不完整返回 503。端点无鉴权，只能在可信本机或受保护内网使用。
- Swagger 依赖已装（DTO 有 ApiProperty），但 main.ts 未挂载文档端点。
