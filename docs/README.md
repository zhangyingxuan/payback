# PayBack - 知识库

PayBack 是个人 A 股短线交易复盘/盯盘系统：定时爬取同花顺/问财行情数据入库，提供 Vue3 看盘后台，并向企微/飞书推送快讯与早盘竞价消息。本知识库按 AI-first 路由组织，人类与 AI 共用。
