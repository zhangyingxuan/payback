# 功能需求清单

> 最后验证：2026-10-13

本文按模块列出 PayBack 已实现与规划中的功能及验收标准。

## 数据采集（server）

**F-01 行情定时采集**
每个交易日按 `scheduler-task/config.ts` 时刻表自动采集资金、热榜、市场、板块、短线、竞价、新股、概念板块数据入库。
- [ ] 交易日各时刻任务按预期触发并写入对应表
- [ ] 非交易日/节假日不产生脏数据（tradeDateUtil 判断）
- [ ] 采集失败按 `TASK_RETRY_TIME` 重试并发企微告警

**F-02 手动触发采集接口**
`/pay-back/crawlTodayData`、`crawlBinddingData`、`crawlSpecialStockData`、`crawlHotListData` 等可手动补采。
- [ ] 收盘后可手动补采当日数据且不重复入库

**F-03 新闻快讯抓取**
7-23 点每 2 分钟抓取新闻（push-server 侧财联社快讯）。
- [ ] 重要消息（color==='2'）能被过滤并推送

## 看盘展示（client）

**盘面观察**
汇总实时请求的市场指数、成交额、涨跌家数、概念板块涨跌、行业资金、短线情绪及部分外围指数。
- [ ] 行情刷新失败时保留已取得的数据，并展示错误提示和时间；外围行情注明可能延迟或休市

**F-04 盯盘看板**
charts 模块 tabPane：Evenly 板、热榜、板块，支持折叠与勾选过滤。
- [ ] 各 tab 正确渲染当日数据；checkbox 点击不触发看板折叠

**F-05 复盘展示**
按日期查询复盘数据（短线周期、市场/投机/板块情绪、龙头）。
- [ ] `fetchReveiwDataByDate` 任意历史交易日返回正确存档

**F-06 短线行情**
涨停/跌停数、封板率、最高连板、连板梯队（按概念分组）。
- [ ] 连板梯队原始数据完整展示

**F-07 文章/资讯管理**
Markdown 编辑、CRUD、列表与详情。
- [ ] 登录后可编辑并发布，前台可见

## 消息推送（push-server）

**F-08 快讯推送**
重要快讯实时推企微机器人与飞书 bot。
- [ ] 双通道均送达，飞书签名（HMAC）校验通过

**F-09 早盘 9:25 竞价推送**
新股与集合竞价涨停（按封单量排序）推送飞书卡片。
- [ ] 每交易日 9:25 触发一次，卡片格式正确

## 同花顺联动（server / ths-trade）

**F-10 自选股/板块同步**
尾盘后自动将策略标的加入同花顺自选；支持按代码/中文名增删自选股与板块。
- [ ] 受 `system-config` 中"自选添加开关"控制
- [ ] Playwright 抓取会话异常时有企微告警

## 系统能力

**F-11 用户认证**
JWT 登录 + svg-captcha 验证码，全局守卫。
- [ ] 未登录请求被 401；`@Public()` 接口放行

**F-12 系统配置**
自选开关、竞价配置、新闻推送开关可查改。
- [ ] `toggleNewsPushEnable` 实时生效

**F-13 数据健康检查**
`fetchDataHealth` 返回各表当日数据完备性。
- [ ] 缺采的表能被识别并列出

**F-14 Gitee webhook 自动部署**
push 事件验签后按 WATCH_DIRS 白名单 git pull 部署，结果推送通知。
- [ ] 非目标分支/伪造 token 不触发部署

## 规划中（未实现）

**F-15 每日 AI 复盘** — 收盘后调 Gemini 生成次日方向与板块/个股建议存档，失败降级规则结果。详见 `../superpowers/specs/2026-08-30-daily-ai-review-design.md`。
**F-16 MCP 只读数据服务** — 独立仓库 payback-mcp，将复盘数据封装为只读 MCP tools。详见 `../superpowers/specs/2026-10-13-payback-mcp-design.md`。

## 每日 AI 全景复盘

按交易日归档大盘、概念与行业涨跌排行、连板梯队、跌停个股、生成时外围指数及 AI 复盘；网页支持选择历史日期和手动生成。外围行情显示各自报价时间，缺失数据明确标注。
