# Pay-Back 支付方案调研报告

> 最后验证：2026-10-13

- **调研对象**：A 股短线交易辅助工具（NestJS + Vue3 自建服务，订阅制 SaaS 商业化方向，目标用户为中国大陆个人投资者）
- **调研日期**：2026-10-10
- **方法**：多路并行搜索 → 抓取 24 个来源 → 提取 101 条论断 → 对 25 条关键论断做三票对抗性核验（确认 21 条、推翻 4 条）→ 综合
- **重要声明**：本报告基于公开资料核验，**不构成签约或法律依据**。支付平台政策按月动态调整（微信自动续费新规 2025-07 生效且每月考核），正式接入前必须重新核对官方当日口径。

---

## TL;DR 核心结论

1. **纯个人身份无法直连微信/支付宝收款**，至少需注册主体（个体工商户起步）。
2. **自动续费是最大门槛**：2025-07 起微信委托代扣仅向企业/政府/事业单位/社会组织开放，个体工商户被明确排除；支付宝"商家扣款"要求注册资本 ≥2000 万元 + 月均主动支付用户 ≥300 人。**初创期应默认走"手动续费"，不要为自动续费设计产品。**
3. **比支付通道更硬的是类目合规**：证券/期货信息服务类目需《经营证券期货业务许可证》，个人和个体户拿不到；已有"云财经"无证销售荐股软件被罚没近 1100 万元的执法先例。**先划清"非荐股/非投资建议"的功能边界，再谈收款。**
4. 推荐路径：**MVP 人工收款验证 → 注册有限公司 + ICP 备案 → 微信 Native 扫码 + 支付宝网站支付做手动续费订阅 → 规模达标后再申请自动续费**。

## 一、主体资质决定可用渠道（置信度：高，3-0 核验）

| 主体 | 微信支付直连 | 支付宝直连 | 自动续费 |
|---|---|---|---|
| 纯个人（自然人） | ❌ 不可申请 | ❌ 不可申请 | ❌ |
| 个体工商户 | ✅ Native/JSAPI/网站支付 | ✅ 电脑/手机网站支付 | ❌ 微信明确排除（2025-07 新规） |
| 有限公司 | ✅ | ✅ | ✅ 可申请，但叠加经营规模考核 |

- 微信申请材料一律要求**营业执照 + 法人身份证 + 银行账户**，官方准入指引未列任何自然人类别。
- 技术前置：自建网站域名**必须完成 ICP 备案**并绑定为商户私有域名，才能开通 Native/JSAPI（官方硬性要求，2026 年商户平台流程要求填报 ICP 备案号）。
- 服务商代开通道（微信 2401 小微商户、2500 个人卖家）限线下行业，不适用于本项目线上订阅。

## 二、费率、到账与退款（置信度：高，3-0 核验）

- **申请费**：无。微信/支付宝均不收接入申请费。
- **交易费率**：与所选经营类目相关，官方口径 **0.6%–1% 不等**；主流类目/个体工商户通常约 **0.6%**（小微有 0.38%/0.54% 活动费率，特殊类目可达 1%–2%）。
  - ⚠️ **未证实项**："证券信息服务"在微信/支付宝类目费率表中实际落入哪一档，本次调研未取得可靠来源，需进件时确认。
- **结算**：T+1 至商户基本账户（提现不二次收费）。
- **退款**：按规则退还手续费（2026-09 媒体口径，与官方 FAQ 一致）。

## 三、自动续费门槛——本项目的决定性约束（置信度：高，3-0 核验）

### 3.1 微信委托代扣/自动续费

财付通《微信支付自动续费管理规则调整公告》（2025-07-28 发布、07-30 生效，2026 年现行）：

- **主体**：仅企业、政府机构、事业单位、社会组织特约商户及其服务商。**个体工商户出局**。
- **经营规模考核**（按月动态调整）：
  - 最近 4 个自然周有效订单去重用户 ≥300 且升级投诉率 ≤0.05% → 维持 T+0/T+1
  - 用户 20–300 → 结算拉长为 **T+7**
  - 新主体/用户 <20 → 结算拉长为 **T+14**
- 含义：即使升级为公司，**冷启动期也会被动接受长账期**。

### 3.2 支付宝"商家扣款"（周期扣款）

- 仅认证**企业**账号；且需**注册资本 ≥2000 万元人民币** + 已开通收单 + 近半年每月主动支付用户 ≥300 人。
- 小型创业团队基本不可行。（注：支付宝"预授权支付"是押金冻结类产品，与此不同，勿混淆。）

### 3.3 微信小程序"会员订阅"（虚拟支付自动续费）

- 前置：已接入虚拟支付、首次发布满 90 天、完成认证备案、**限企业等组织主体**、近 30 天日均 DAU ≥1000（部分官方页面写 ≥1 万）、缴纳交易保证金。
- **费率高**：首笔 1% 或 10%（视行业/限时激励），**第二笔及后续周期扣款均为 10%**，显著高于普通 0.6%。
- 结论：不适合初创期。

### 3.4 综合判断

> 三大自动续费通道对初创产品全部关闭或代价过高。**首期订阅必须设计为"到期提醒 + 用户主动续费"**，这是渠道事实约束，不是产品偏好。

## 四、类目合规：比支付更硬的红线（置信度：高，3-0 核验）

- 微信公众平台/小程序开放类目中，金融业一级类目下含"证券/期货"、"证券/期货投资咨询"子类目，申请需**《经营证券期货业务许可证》**——仅核发给证券公司、期货公司及证券投资咨询机构，个人与个体户无法取得。微信对涉股内容有资质强约束，处罚可至封号。
- 纯行情展示可尝试"股票信息服务平台"类目（需 ICP 许可 + 交易所信息经营授权），个人同样难满足。
- **执法先例**：深圳证监局〔2023〕行政处罚 4 号——云财经未取得证券投资咨询资格，2016–2019 年销售"涨停先驱者""早盘捉妖""N型反转大师"等荐股软件，**没收违法所得 548.61 万元并处同额罚款，罚没合计近 1100 万元**（定性依据：《证券法》非法经营证券业务 + 证监会〔2012〕40 号"荐股软件"规定）。
- **启示**：支付通道打通 ≠ 经营合法。本项目当前形态（推送涨停梯队/连板选股）恰好踩在"荐股软件"定性区间内，商业化前必须先完成上一轮分析所述的功能去荐股化。

## 五、个人阶段的轻量选项（置信度：中，2-1 核验）

- **支付宝AI收**（2026-04-28 上线）：面向商家和**个人开发者**，个人实名账号可签约，按调用/按量即时收款、自动结算，支持 X402 协议。
  - 限制：适用场景为 AI Agent 按调用计费，**能否承接"订阅制网页产品"收款无一手依据**；"0 费率至 2026-12-31"的说法已被核验推翻，勿作为成本假设。
- 更朴素且零风险的 MVP 方式：收款码/对公转账 + 手工开通权益，先验证付费意愿。

## 六、待验证项（本次未获得通过核验的来源，不作为结论）

1. **Stripe / Paddle / Lemon Squeezy 等海外渠道**：对中国大陆用户收 A 股资讯订阅费，涉及跨境收单、结汇、无增值税发票，且用海外通道规避国内类目资质可能被认定非法经营——**方向性判断是不适用，但缺三票验证来源**。
2. **聚合支付服务商**（易宝、汇付天下、Ping++ 类）：金融资讯类目的实际进件政策、费率、二清（无证归集资金）风险。
3. 手动续费是否会被平台风控认定为变相自动续费。
4. "非荐股纯数据工具"是否仍需证券类许可证（法律口径，建议咨询律师）。

## 七、推荐落地路径

### 阶段 0：MVP 人工收款（个人主体，0 接入成本）
- 收款码/转账 → 管理员手动开通订阅字段；验证付费意愿（目标：≥10 个付费用户）。
- 同步完成功能去荐股化改造与"不构成投资建议"免责声明。

### 阶段 1：正式直连 + 手动续费（有限公司 + ICP 备案）
- **直接注册公司，跳过个体工商户**——个体户能收款但开不了自动续费，将来还要主体迁移。
- 渠道：**微信 Native 扫码（PC）+ 支付宝电脑/手机网站支付**；预算费率 0.6%（类目档位需进件确认）。
- 技术接入要点（基于通用工程实践 + 官方文档，实施时按 V3 文档逐条核对）：
  - `orders` 表：`order_no`、`user_id`、`plan`、`amount`、`channel`、`status(pending/paid/refunded/closed)`、`expires_at`
  - 回调：验签（微信 V3 平台证书/微信支付公钥）、**金额与本地订单强比对**、以 `transaction_id` 做幂等键、处理微信异步通知重试
  - 对账：每日下载官方交易账单核对；差异告警
  - 权益发放：支付成功 → 更新 subscription → push-server/scheduler 按 quota 放行
  - 续费：到期前站内/推送提醒，用户主动下单（一期不做代扣）

### 阶段 2：自动续费（企业主体 + 规模达标）
- 满足"4 周去重付费用户 ≥300、升级投诉率 ≤0.05%"后申请微信委托代扣；接受 T+7/T+14 过渡账期。
- 评估是否值得：若客单价低、用户粘性靠提醒即可，长期停留在手动续费也成立。
