# 休市日历实施计划

目标：core 维护已核验年度休市数据，前后端共享日期语义；非交易日仅热榜定时任务继续执行。

已批准设计：本次会话中的年度休市表方案。采用 TypeScript、现有 Cron 和 Vue Composition API，不增加依赖、数据库或管理接口，不提交代码。

- [x] core：新增 `src/calendar/data/2026.ts`、`src/calendar/index.ts`，从 `src/main.ts` 导出。提供 `toShanghaiDate`、`getTradingDayInfo`、`getNextTradingDay`，测试非法日期、时区、周末、假期边界及超出年份。
- [x] 调度：默认仅交易日运行，热榜显式豁免。所有注册入口传递配置，未知日期按天告警，保留防重入及一次性删除；测试回调执行、跳过及跨日期变化。
- [x] 客户端：替换节日偏移数组，使用共享日历显示休市/开市提示；时钟响应式更新并卸载清理计时器。
- [x] 验证：先运行失败测试，再实现；运行 core 测试、调度测试和依赖顺序构建，更新技术和业务文档，检查临时产物。

重点：休市区间包含首尾、调休周末不开市、2027 未核验返回未知、上海跨日重新判断、节日当天不等于休市开始日。

结果：core 5 组测试、调度 4 组测试通过；Lerna 按依赖顺序构建 core/server/client 成功。独立审查未发现阻塞问题。core 构建仍输出仓库已有 ESLint 解析配置错误，退出码为 0，未扩展整改范围。

实施调整：移除客户端把 core 声明为 any 的旧声明，修复因此暴露的两个调用类型问题：策略使用已计算的实际连板高度，周期查询显式传入缺省的昨日数据。构建临时使用 Git 工具路径提供 rm，未改全局配置。恢复验证产生的前端 dist/stats 和原本干净的服务端 dist 文件；保留原有未提交改动，不生成提交。
