# 知识库维护制度

> 最后验证：2026-10-13

本文定义知识库的持续维护规则，确保文档与代码同步演化。

---

## 1. 文档保鲜规则

### 验证日期

每份文档头部包含 `> 最后验证：YYYY-MM-DD`。

| 状态 | 条件 | 动作 |
|------|------|------|
| 新鲜 | ≤ 30 天 | 无需动作 |
| 需复查 | 31-90 天 | 下次涉及该领域时优先复查 |
| 可能过期 | > 90 天 | 主动安排复查 |

### 谁负责更新

| 分类 | 责任人 | 复查频率 |
|------|--------|----------|
| 01-需求分析 | 项目负责人 | 需求变更时 |
| 02-业务梳理 | 项目负责人 | 业务流程/调度时刻变更时 |
| 03-架构设计 | 技术负责人 | 架构决策变更时 |
| 04-技术方案 | 对应开发者 | 代码变更后 |
| 05-API文档 | 后端开发者 | API/表结构变更后 |
| 06-开发规范 | 技术负责人 | 依赖/规范变更时 |
| 07-测试用例 | 开发者 | 功能变更后 |

（本项目为单人维护为主，责任人默认 = 当前迭代负责人。）

## 2. 分类索引维护规则

每个分类目录下有一个 `_index.md`，AGENTS.md 通过两级路由依赖这些索引。

### 新增文档时
1. 在对应分类目录创建 `.md` 文件（含头部验证日期与尾部相关文档）
2. 在对应 `_index.md` 表格中新增一行（触发关键词 + 一句话说明）
3. 更新 `README.md` 导航链接；若产生新路由规则，同步 `AGENTS.md`

### 索引健康检查
```bash
bash scripts/check-index-coverage.sh
```

### 外部工件（superpowers/ 与 mcp-agent/）
`docs/superpowers/` 与 `docs/mcp-agent/` 是相关 skill 的产物目录，保留原位、不移动不删除，只在 03/04 索引中登记引用；不参与过期检查。

## 3. 代码→文档触发规则

| 代码变更 | 必须检查文档 | 检查内容 |
|----------|-------------|----------|
| `packages/server/src/**/*.controller.ts` | `05-API文档/接口文档.md` | 端点增删、方法、前缀 |
| `packages/server/src/**/entities/*.entity.ts` | `05-API文档/数据库设计.md` | 字段、类型、风险注记 |
| `packages/server/src/scheduler-task/config.ts` | `02-业务梳理/业务流程.md`、`04-技术方案/后端技术方案.md` | 交易日时间线表 |
| `packages/core/src/config/index.ts` | `02-业务梳理/术语表.md`、`04-技术方案/后端技术方案.md` | 问财查询条件与术语 |
| `packages/client/src/views/**`、`router/**` | `04-技术方案/前端技术方案.md`、`01-需求分析/功能需求清单.md` | 页面清单与功能编号 |

| `docker-compose*.yml`、`.env*`、`nginx.conf` | `04-技术方案/环境配置.md` | 端口、env key |
| push-server `@EventPattern`、webhook 流程 | `04-技术方案/推送与部署方案.md` | 事件与部署链路 |

## 6. 文档编写规范

### 文档头部
```markdown
# 文档标题

> 最后验证：YYYY-MM-DD

本文描述...（一句话用途）
```

### 文档尾部
每份文档末尾包含「相关文档」区块，相对路径链接。

### 其他
- 单份 ≤ 200 行，超过拆分
- 中文命名；分类目录 `NN-分类名`
- `_index.md` 是元数据单一数据源，文档内不重复登记触发词
- **禁止写入任何密钥值**，env 只写 key 名（历史教训：.env.dev 曾泄密后脱敏）

## 7. 度量指标

| 指标 | 计算方式 | 目标 |
|------|----------|------|
| 文档新鲜度 | 30 天内验证文档占比 | ≥ 80% |

| 链接有效性 | 内部链接无断链 | 100% |
| 索引覆盖率 | _index.md 引用数 / 分类内 .md 总数 | 100% |
