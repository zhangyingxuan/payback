# 受控研究回归用例

> 最后验证：2026-11-19

范围包含受控取数、爱问财接入、隔离 Python、任务恢复与待审导出，不包含任意宿主执行或多用户服务。

## 验证入口

在同级 `payback-agent` 执行 `uv run --frozen pytest -q`。2026-11-19 爱问财接入后为338通过、5跳过（续批312通过）；所有单元测试的外部网络/容器调用均替换为假实现。真实容器及爱问财取数另行手工冒烟。

| 文件 | 必须覆盖的行为 |
|---|---|
| tests/test_research_http.py | 私网/混合 DNS/映射 IPv6 拒绝；固定 IP 与 TLS 原域名；无自动重定向；超大、截断、压缩和二进制响应拒绝；慢速头/正文预算；中文编码及非法 UTF-8 |
| tests/test_research.py | 固定来源与凭据绑定；参数类型/范围/未知约束拒绝；密钥原文回显脱敏；来源策略每次重读；坏策略不阻断独立公开 fetch/search；未配置与代码执行请求明确失败 |
| tests/test_research_jobs.py | 立即提交、四个活动任务和物理有界队列；取消优先；证据原子落盘、时间/摘要、分段读取；路径穿越与未知 ID；失败清理不终止 worker；64 份及过期清理 |
| tests/test_research_sandbox.py | 固定镜像、rootless/cgroup/seccomp 预检、容器实际 Seccomp 门禁、无宿主回退、stdin/输出边界、取消/超时和有界代码错误诊断 |
| tests/test_research_iwencai.py | 既有首屏/分页地址、表单、共享签名、合法零与错误区分、嵌套错误、股东表拒绝、条件规范化、重复代码、取消、管理员覆盖 |
| tests/test_tools_source.py | 默认不启用、启用后工具聚合、同名拒绝、关闭清理；真实 ask 循环提交/状态/结果的假网络端到端验证 |
| tests/test_prompt.py | 来源优先、公开搜索词、非忙轮询、统计与取数成功区分、无代码执行 |

## 手工检查及未验范围

- 真实公开 HTTPS 冒烟：Python 官网 robots.txt 成功读取 537 字符；example.com 存在网络超时。网络失败必须返回结构化错误，不伪造响应。
- 续批真实 Podman 冒烟已验证非 root、无宿主凭据、无网络、只读目录、内存/CPU/pids/NoNewPrivs、输出上限、超时和取消；脚本为 Agent `scripts/smoke_research_sandbox.py`，需管理员传固定镜像摘要。另已实测语法错误返回类型和行号。
- 续批增加：跨 MCP 重建、进程重启证据查询、显式恢复、目录单写锁、输入依赖保留、64份边界重启、完整产物元数据摘要、待审导出；单位测试仍不访问真实引擎和供应商。
- 爱问财真实首屏可用；分页顶层成功但内部业务码-1201，已保留首屏并标记 upstream_paging_error/complete=false。没有验证全量名单、原问题的复权语义、Brave 真实密钥/额度或公网鉴权。
- 测试中的 socketpair 仅为本机离线连接，不访问外部数据源；Windows 底层阻塞由明确 socket 超时和逐次接收预算共同约束。
- 任务取消不能撤回已发出的请求；中断任务不自动重发，显式恢复可能再次计费。请求及代码明文保存，草案同样受24小时/64份留存约束，不以绿色单测宣称全市场统计口径已验证或平台已上线。
