# 测试策略与用例

> 最后验证：2026-10-13

## 现状

- 仓库内**没有生效的自动化测试**：nx 配置排除了 spec/test 文件参与构建缓存，client/server 无测试脚本；AI 复盘等新功能计划在 server 引入 Jest。
- 质量兜底三件事：client `vue-tsc --noEmit` 构建门禁、`fetchDataHealth` 数据完备性检查、企微采集失败告警。
- 本清单以**手动回归**为主；新增自动化时在此登记分层。

## 测试分层（规划）

| 层 | 范围 | 工具 |
|----|------|------|
| 单元 | core utils（hexin-v、asynTaskIterator）、tradeDateUtil、schedulerUtil | Jest（待建） |
| 集成 | TypeORM entity↔MySQL、动态 Cron 注册 | server 测试库（待建） |
| API | 采集触发与查询端点冒烟 | curl/脚本（待建） |
| 手动 | 看盘展示、推送送达 | 见下方清单 |

## 发布前回归检查清单（手动，必做）

**账号与框架**
- [ ] GET /auth/getCode 出验证码；正确账密可登录，错误被拒
- [ ] 未带 token 访问业务 API 返回 401；`@Public` 接口正常

**采集与数据（server）**
- [ ] `initSchedulerTask` 注册日志任务数与 config.ts 一致
- [ ] 手动 `crawlTodayData`/`crawlPlateData`/`crawlHotListData` 返回成功且入库
- [ ] `fetchDataHealth` 当日各表无缺失
- [ ] 采集失败模拟（断网/错误 token）→ 企微告警送达、按 TASK_RETRY_TIME 重试

**展示（client）**
- [ ] 盯盘三个 tab（Evenly 板/热榜/板块）数据渲染；tab 内勾选复选框不触发看板折叠（回归 b401372）
- [ ] 复盘页按历史日期查询返回存档；短线页连板梯队完整
- [ ] 概念分组（按题材）与最新概念板块页正常

**推送（需交易日 + Consul + push-server 在跑）**
- [ ] 9:25 早盘飞书卡片：新股 + 竞价涨停按封单量排序
- [ ] 重要快讯（color==='2'）企微 + 飞书双通道送达
- [ ] `toggleNewsPushEnable` 关闭后不再推送

**部署链路（webhook-server）**
- [ ] push 目标分支后收到部署 notice；伪造 X-Gitee-Token 被拒
- [ ] 非 WATCH_DIRS 变更不触发 git pull

**同花顺联动**
- [ ] 受 systemConfig 开关控制：isAutoAddSelf 关闭时尾盘不加自选
- [ ] addThsSelfStock / delThsSelfPlateByNameCn 单链路可用（Playwright 1.35 镜像内）

## 用例示例（P-01 早盘竞价推送）

- 前置：交易日 9:20，consul/push-server/server 全部在线，isAutoPushNews=1
- 步骤：等待 9:25 任务触发（或手动调 `crawlBinddingData` 后触发推送事件）
- 预期：飞书群 1 分钟内收到卡片，含新股列表 + 竞价涨停股按封单量降序，无重复推送
- 异常：Consul 不可用时 server 日志告警但不阻塞采集（降级确认）
