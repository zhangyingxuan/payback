# 前端技术方案

> 最后验证：2026-10-13

packages/client：Vue 3 看盘后台。

## 工程结构

```
src/
├── main.ts / App.vue
├── api/          # 按域封装：payBack、thsTrade、systemConfig、user、article、tonghuashun；model/ 放类型
├── store/        # Pinia：permiss(权限)、sidebar、tags；pinia-plugin-persist 持久化
├── router/       # index.ts 路由表；auth.ts 全局守卫(JWT)
├── views/        # dashboard、home、charts(盯盘核心)、article、news、shortTerm、
│                 # latestConceptPlate、works、systemConfig、login、user、permission、403/404 等
├── components/   # header、sidebar、drawer、plate、stock、tags、stockPopover/Tooltip、
│                 # platePopover、commonDialog、calendar
└── styles/       # variables.less 等
```

## 关键机制

- **UI 组件**：Element Plus 按需自动导入（unplugin-auto-import + unplugin-vue-components，ElementPlusResolver），组件不手写 import。
- **请求**：axios 走相对前缀，由 vite proxy 转发：`/blowsysun`→VITE_BASE_API、`/tonghuashun`、`/thsNews`、`/thsDq`→对应同花顺域名（changeOrigin + rewrite 去前缀）。生产由 nginx 反代同名前缀。
- **路由**：hash 模式（VITE_ROUTER_HISTORY），`base='./'` 适配子路径部署；`router/auth.ts` 做登录态与权限拦截。
- **core 依赖**：dev 下 alias `pay-back-core → ../core/src/main.ts`（源码直用，改动即时生效）；构建走 workspace 包。
- **盯盘 charts 模块**：tabPaneCharts（Evenly 板/热榜/板块 tab）、components/utils/styles 分层；近期交互约定：tab 内 checkbox 点击不得冒泡触发看板折叠。

## 构建与优化

- `build = vue-tsc --noEmit && vite build`：类型错误直接构建失败，禁止 `as any` 绕过。
- manualChunks 分包：vendor-vue / element-plus / echarts / zrender / markdown / utils / libs + 每视图 `page-{name}`。
- 产物 gzip + brotli（vite-plugin-compression）；rollup-plugin-visualizer 产出 stats.html；terser 去 console；sourcemap 关闭。
- 模式：`vite --mode test/production` 对应 `.env.test` / `.env.production`。

## 监控

- aegis-web-sdk 前端异常监控（main.ts 接入）。
