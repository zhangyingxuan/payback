# 环境配置

> 最后验证：2026-10-13

各服务端口、环境变量 key 清单（不含值）与启动方式。

## 端口速查

| 服务 | 端口 | 说明 |
|------|------|------|
| client dev | 8888（VITE_PORT） | vite dev server |
| client 容器 | 8080 | nginx，挂 nginx.conf |
| server | 3000 | 全局前缀 /blowsysun，nginx 反代同名 |
| push-server | 3001 | TCP 微服务，非 HTTP |
| webhook-server | 3002（APP_PORT 可覆盖） | HTTP |
| MySQL | 3306 | 5.7 |
| Consul UI/API | 宿主 18500 → 容器 8500 | dev agent |

> 所有 Node 服务启动时经 portManager 检测占用并自动换端口，实际端口以日志为准。

## 环境变量（key 名清单，值放各机 .env，禁止提交）

**packages/server**：`.env.dev` / `.env.prod`（NODE_ENV 选择）
`DDD_HOST` `DDD_PORT` `DDD_USER` `DDD_PD`(base64) `DDD_NAME`（MySQL）、`CONSUL_HOST` `CONSUL_PORT`、`APP_NAME` `APP_HOST` `APP_PORT`、`TASK_RETRY_TIME`

**packages/client**：`.env` / `.env.development` / `.env.test` / `.env.production`
`VITE_PORT` `VITE_PUBLIC_PATH` `VITE_ROUTER_HISTORY` `VITE_BASE_API` `VITE_BASE_API_THS` `VITE_BASE_API_THS_DQ` `VITE_BASE_API_THS_NEWS`；prod 另有 `VITE_CDN` `VITE_COMPRESSION`

**packages/webhook-server**：Gitee `TOKEN`、`TARGET_BRANCH`、`WATCH_DIRS`、`APP_PORT`、Consul 相关
**packages/push-server**：企微 robotList webhook、飞书 bot webhook 与签名密钥、Consul 相关

历史教训：`.env.dev` 曾被误提交，后以占位符脱敏（commit cea9893）——新增 env 文件务必检查 gitignore。

## 本地启动

```bash
pnpm install                # 根目录，Node >= 22
pnpm start:server           # 后端 3000
pnpm start:client           # 前端 8888（--mode test）
pnpm start:pushServer       # 推送 3001
docker-compose -f docker-compose-consul.yml up -d   # 需要 Consul 时
```

无 Consul 时 server 找不到 push-server 只会告警，API 正常；推送功能需先起 consul 再起 push-server（注册），后起 server（发现）。

## Docker 编排

- `docker-compose.yml`：client + server + mysql 同 bridge 网络 mysql_bridge；server 依赖 mysql，restart: on-failure；MySQL 5.7 daocloud 镜像，数据/配置卷挂宿主机。
- 根 `dockerfile`：Playwright v1.35.0-jammy 抓取镜像，COPY packages/server，装 firefox。

## 生产域名线索

dev 的 `VITE_BASE_API` 之一指向 blowsysun.top；服务器经 nginx 反代 `/blowsysun` → server:3000、静态资源 → client 容器。具体机器地址见运维保管的 .env，不入库。
