# 术语表

> 最后验证：2026-10-13

A 股短线领域术语与项目内部黑话速查。

| 术语 | 全称/英文 | 含义 | 项目语境 |
|------|-----------|------|----------|
| 涨停/跌停 | limit up/down | 单日涨/跌幅达上限（主板 10%，创业板/科创板 20%） | `shortTermData` 记录涨停/跌停数 |
| 封板率 | - | 涨停后收盘仍封住的股票占比 | 短线情绪指标 |
| 连板 | - | 连续多日涨停 | `shortTermData` 存连板梯队原始数据（mediumtext） |
| 炸板 | - | 涨停盘中被打开 | 问财查询条件之一（core/src/config） |
| 集合竞价 | opening auction | 9:15-9:25 撮合定价 | 9:25 采集竞价数据并推送涨停封单（按封单量排序） |
| 封单量 | - | 涨停价上的买单挂单量 | 早盘飞书卡片排序依据 |
| 龙头 | - | 板块内领涨/人气最高个股 | `reviewData` 复盘记录龙头 |
| 短线周期 | - | 市场情绪从冰点到高潮的循环阶段 | `reviewData.shortTermCycle` |
| 题材/概念板块 | concept plate | 按热点主题划分的股票分组 | `latestConceptPlate`、`plateData` |
| 行业板块 | industry plate | 按行业划分的分组 | `plateData` 记录涨停最多的概念/行业板块 |
| 北向/南向资金 | northbound/southbound | 沪深港通资金流向 | `fundsData` |
| 主板 | main board | 沪/深主板（10% 涨跌幅限制） | 问财条件按板块区分 |
| 问财 / iwencai | - | 同花顺自然语言选股平台 | 核心数据源；查询语句集中在 `core/src/config/index.ts` |
| 10jqka | 同花顺 | 数据源域名 10jqka.com.cn | client 代理前缀 `/tonghuashun`、`/thsDq`、`/thsNews` |
| hexin-v | - | 同花顺反爬校验 token | `core/src/utils/hexin-v` 本地生成，绕过需保版本兼容 |
| ths-trade | Tonghuashun trade | 同花顺自选股/板块增删模块 | `/ths-trade` 控制器，Playwright 操作 |
| Evenly 板 | EvenBoard | 盯盘看板 tab 之一 | `fetchEvenBoardData` |
| 复盘 | review | 当日市场情绪与结构总结 | `reviewData` 表；AI 复盘功能规划中 |
| 热榜 | hot list | 热门个股/板块/ETF 排行 | `hotList` 表，7-23 点每 30 分采 |
| 竞价配置 | binding config | 集合竞价推送参数 | `systemConfig` 表字段 |
| blowsysun | - | 项目 API 全局路由前缀/品牌名 | `/blowsysun/*`，nginx 反代同名 |
